## Основной сценарий реального API

| Метод | Проверяемое действие | Успешно проверенное условие |
| --- | --- | --- |
| GET | Предварительная проверка доступа к `/v1/disk` | HTTP 200 |
| PUT | Создание уникальной папки прогона и дочерней папки `source` | HTTP 201 для каждого запроса |
| GET | Чтение метаданных `source` | HTTP 200 и тип `dir` |
| POST | Копирование `source` в `copy` | HTTP 201 или 202, затем HTTP 200 при чтении `copy` |
| DELETE | Удаление `copy` | HTTP 204 или 202, затем HTTP 404 при чтении `copy` |
| DELETE | Очистка уникальной папки в `@AfterEach` | HTTP 204 или 202, затем HTTP 404 при чтении папки; HTTP 404 на DELETE также допустим, если ресурс уже отсутствует |

Для POST и DELETE таблица показывает допустимые коды из утверждений теста. Конкретная синхронная или асинхронная ветка в журнал успешного прогона не записывалась. Удаление временной папки подтверждено завершающей проверкой HTTP 404.

## Новые проверки

| Сценарий | Проверенный результат |
| --- | --- |
| GET с заведомо неверным токеном | HTTP 401, JSON с непустым `error` |
| GET отсутствующего ресурса | HTTP 404, JSON с непустым `error` |
| DELETE отсутствующего ресурса | HTTP 404, JSON с непустым `error` |
| Повторное создание папки через PUT | HTTP 409; после ошибки GET возвращает исходную папку с типом `dir` |
| Копирование отсутствующего источника через POST | HTTP 404; GET целевого пути также возвращает HTTP 404 |
| Кодирование кириллицы и `+ & # % ? =` в обоих путях POST | Локальный HTTP-сервер получил обе строки без искажений и ровно два query-параметра |

Каждый интеграционный тест выполняется независимо. Три сценария, создающие папки, прошли очистку в `@AfterEach` с подтверждением HTTP 404. Отдельно проверен запуск без живого режима: пять локальных тестов прошли, шесть интеграционных были пропущены.

Сводка прогона и результаты всех 11 тестовых методов сохранены в [live-api-result.json](live-api-result.json). Исходные локальные отчёты Maven находятся в игнорируемом каталоге `target/surefire-reports/` и будут перезаписаны следующим запуском тестов. [Предыдущая проверка базового набора из пяти тестов](https://github.com/pepepoopoon/yandex-disk-api-tests/blob/510fdd2c8c4c7c7b9400f070c88e87ee181a3a70/docs/live-api-verification.md) сохранена в истории репозитория.

Этот результат относится к указанной версии и дате. GitHub Actions выполняет локальные HTTP-тесты без токена; для повторного живого прогона нужен OAuth-токен тестовой учётной записи.
