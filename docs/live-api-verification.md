## Что проверил живой сценарий

| Метод | Проверяемое действие | Успешно проверенное условие |
| --- | --- | --- |
| GET | Предварительная проверка доступа к `/v1/disk` | HTTP 200 |
| PUT | Создание уникальной папки прогона и дочерней папки `source` | HTTP 201 для каждого запроса |
| GET | Чтение метаданных `source` | HTTP 200 и тип `dir` |
| POST | Копирование `source` в `copy` | HTTP 201 или 202, затем HTTP 200 при чтении `copy` |
| DELETE | Удаление `copy` | HTTP 204 или 202, затем HTTP 404 при чтении `copy` |
| DELETE | Очистка уникальной папки прогона в `finally` | HTTP 204 или 202, затем HTTP 404 при чтении папки |

Для POST и DELETE таблица показывает допустимые коды из утверждений теста. Конкретная синхронная или асинхронная ветка в журнал успешного прогона не записывалась. Удаление временной папки подтверждено завершающей проверкой HTTP 404.

Сводка прогона сохранена в [live-api-result.json](live-api-result.json). Исходные локальные отчёты Maven находятся в игнорируемом каталоге `target/surefire-reports/` и будут перезаписаны следующим запуском тестов.

Этот результат относится к указанной версии и дате. GitHub Actions выполняет локальные HTTP-тесты без токена; для повторного живого прогона нужен OAuth-токен тестовой учётной записи.
